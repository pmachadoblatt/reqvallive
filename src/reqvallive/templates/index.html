Live requirement validation

How this works

  1. Import requirements from SysON. Documentation = marker _go_to_verification; Success Criteria = model elements.
  2. Gate ACCEPT/REJECT runs before measurement (MSFC / SIS-08 Methods).
  3. Connect MQTT, then Start measurement to collect live evidence.
  4. Stop, open the HTML report, optionally generate an LLM narrative, and Publish to SysON.

The app does not invent criteria — it reads SysON as-is. Exported .sysml is an MBSE skeleton, not Magic simulation.
